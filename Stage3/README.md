# Maksab Platform

A B2B marketplace and pricing calculator designed to connect suppliers with retail merchants and simplify product costing and profit margin calculations.

- **Reem** - System Architecture & API Specifications Lead
- **Shahad** - Database Design (ERD) & Sequence Diagrams Lead
- **Shomukh** - Scope, User Stories & UI/UX (Figma) Lead

## 🛠️ Tech Stack
- **Frontend:** React
- **Backend:** Python (Flask)
- **Database:** PostgreSQL
- **Integrations:** Moyasar Payment Gateway, Google Maps API
